## Fix order after the reset

1. **F25, F26, F07, F06: stop sync from destroying Spark output.** Protect filters for `--delete`, `--update` or an `episodes/*/audio/` exclude, checked pulls, and a per-run work dir for make's claude edits. Every other fix is unsafe to test while a sync can revert it.
2. **F08, F27, F28, F29: render-lock hygiene.** Put npm under the lock, set CONC to 4 by default and as the cap, and kill the remote render when ssh drops. These are small shell edits that unblock parallel lanes.
3. **F22, F23, F24: the originality gate.** It currently lets real copies through. Re-run it on every shipped and backlog script after the fix, because some scripts that passed may now FAIL.
4. **F09, F13, F11, F12, F10: script parsing.** Make these hard errors at parse time, before TTS, so a bad backlog script fails in under a second instead of after a full CPU TTS pass. Then add timed music cues and intra-paragraph vox/speed.
5. **F01, F02, F04, F03, F05: make/auto correctness.** Check the claude exit status, invalidate shots when the script changes, add review rollback, write the storyboard atomically, and limit anchors to time keys.
6. **F16, F17, F14: visible quality.** Fix the camera y remap, then drop the `PATCH_16X9` hacks it caused and re-check the 16:9 cuts. Fix SVG aspect. Fix the loudness reference, with `music_db` retuned by -3 dB so the current mixes don't change.
7. **F18, F19, F20, F21, F15: polish.** Caption abbreviations and conjunctions, frame-accurate scene starts, clipping caption pages at cuts, and negative cue clamping.

Remove each test's xfail marker when its fix lands (the tests are strict: a fixed bug shows up as XPASS / unexpected success).
