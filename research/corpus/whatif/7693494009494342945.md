## 2. Structure summary

**Beat sequence (80 s)**

| Beat | Time | % of runtime |
|---|---|---|
| Hook: title card, atom icon, pre-event countdown | 0:00–0:05 | 6% |
| Setup: "you" + named place, calm photoreal scene | 0:05–0:08 | 4% |
| Event + main open loop (HUD flips to return countdown, slow-motion rule, look flips to wireframe) | 0:08–0:09 | 1% |
| Escalation tier 1: senses and body (light, see-through hands) | 0:09–0:21 | 15% |
| Mechanism: rule, then the turn ("charge… repel") | 0:21–0:28 | 9% |
| Breath (no text; matter dissolves) | 0:28–0:32 | 5% |
| Escalation tier 2–3: object → person (bomb, Sun) | 0:32–0:40 | 10% |
| Climax white-out | 0:40–0:42 | 3% |
| Escalation tier 4–6: planet → galaxy → Moon (live counter) | 0:42–1:04 | 27% |
| Return (loop closes) + false resolution + callback | 1:04–1:09 | 6% |
| Twist (return = second blast) | 1:09–1:12 | 4% |
| Black + bookend title + real fact | 1:12–1:20 | 10% |

In short: hook and setup take 10%, escalation takes about 69% (0:08–1:04), the return and twist take 10%, and the outro takes 10%.

**Hook length.** The title card has 7 words (8 counting the HUD's "every atom" subline) and lasts about 5 s before the first caption. The ticking HUD countdown carries the hook until the event at about 8 s, so the first big visual change happens inside 10 s.

**Re-hook interval.**
- New caption every **~6.4 s** on average. Caption start times are 5, 9, 15, 21, 25, 32, 35, 44, 50, 65, 69. The gaps range from 3 s, at the momentum peak, to 15 s, during the cosmic shots, where HUD text fills in.
- Counting every new text element (caption, HUD flip or subline, title/end card), something new appears every **~3.3 s**.
- Hard visual cuts or pattern interrupts land at 0:08 (photoreal to wireframe), 0:28 (dissolve), 0:40 (white-out), 1:04 (blue return city) and 1:12 (black).
- The HUD number changes every frame for the whole event (0:08–1:02), so the screen never holds still.

**Open loops.**

| Loop | Opens | Closes |
|---|---|---|
| A: "what happens in 5 seconds?" | 0:00 title | Answered progressively 0:09–0:56 |
| B: "when do they come back?" (HUD return countdown) | 0:08 | 1:02–1:04 "BACK". At ~54 s this is the longest-held loop. The in-world clock is consistent: 5 s × 11 ≈ 55 s of screen time. |
| C: "will it be OK once they return?" | Implied at 1:04 | 1:09 twist: no |
| D: "Which one next?" (series loop) | Description | Never closes; it feeds comments and the next episode |

Mini-loops sit inside the run: the rule at 0:21 is closed by the consequence at 0:25. "Charges repel" at 0:25 is closed by the bomb at 0:32.

**Escalation ladder.** Perception (light) → own body (hands) → physics rule → smallest object (sand grain = bomb) → person (outshines Sun) → planet (Earth comes apart, counter climbs) → galaxy (outshines Milky Way) → neighbour body (Moon gone) → **reversal** (the fix causes a second, equal blast). Each rung is a bigger scale than the last, and only one idea goes on each caption.

**How it ends.** The return loop closes, a false resolution follows ("returns to where it was"), the setup location comes back ("Central Park, 5 seconds later"), then the twist (it explodes again) and a black beat. The title card repeats so the loop replays cleanly, then a small-caps real fact. The comment CTA lives in the post description, not on screen.

## 3. Transferable skeleton (abstract, no original wording)

Format: 9:16, about 80 s, captions only or very light voice-over (~55 caption wpm). There are three text layers: a centred title card, a lower-third serif caption (one idea, 4–8 words), and a top-left HUD with a label, a large ticking number and a small-caps subline.

1. **0–6% · Premise card.** "What if [basic thing everything depends on] [changed] for [very short time]?" Highlight the key noun in an accent colour and add a simple icon. The HUD counts down to the event, and its subline says how much it affects ("every X has it").
2. **6–10% · Place you.** Second person plus a well-known real place, shown calm and normal.
3. **~10% · Flip.** Hard style change (normal → strange render), sound hit. The HUD switches to a countdown for the change ending, and the subline gives a slow-motion factor. The screen-time length is the real time × that factor, so the clock always adds up.
4. **10–25% · Wonder first.** One or two harmless, beautiful, sense-level effects, the second one on the viewer's own body. This is the screenshot moment.
5. **25–35% · Rule, then a pause.** State the plain science rule in one line. Next, a shorter line that hints at the consequence without saying it. Then 3–4 s with no text while the image breaks apart.
6. **35–50% · Scale inversion.** The smallest everyday object becomes something huge (numerical equivalence), then a person is compared with a giant benchmark. These captions come closest together (~3 s).
7. **~50% · White-out or full-frame pattern interrupt.**
8. **50–80% · Cosmic climb.** Planet, then galaxy, then a neighbouring body. The HUD subline shows a live climbing number ("[thing] IS NOW N [units]") and a terse status line ("[thing] IS GONE"). Caption gaps can stretch to 6–15 s because the HUD is moving.
9. **~80% · Loop closes.** The countdown reaches zero, then the HUD shows "[X] BACK". A reassuring line ("everything returns…") follows, then a callback subline naming the opening place plus elapsed real time.
10. **~85% · Twist.** The return causes a second disaster of equal size. One caption and one HUD equivalence line.
11. **90–100% · Outro.** Black for about 2 s. The title card repeats exactly, for a seamless replay loop. Then one true, surprising small-caps fact tying the premise to the viewer's body ("X is only N% of you, yet …"). The comment CTA ("which one next?") goes in the post description.

Pacing targets: a new text element every ~3–4 s, a new caption every ~6 s, a hard visual cut every ~12–20 s, the HUD number always moving during the event, 8–11 captions in total, and no caption over 8 words.

Code-build notes for our kit: wireframe line-art scenes (SVG strokes on black), particle dissolve (Canvas points), a white-out flash, a glowing sphere with a limb, and an HUD component (mono countdown with ms digits plus a small-caps subline). None of these need generated 3D.
